# IMDB Casting Graph Explorer

This app connects Claude to a Microsoft Fabric IQ Ontology containing **25,000+ IMDB movies**, **80,000+ people**, and **200,000+ casting decisions** — forming a graph that AI models can reason over.

**What makes this different from a dashboard?** You're not querying tables — you're asking an AI to traverse a graph of entities and relationships. The same ontology powers this app, the Fabric Data Agent, and Azure Databricks notebooks — one graph, any model, any surface.

Ask anything:
- 🎭 *"Which actors appeared in both critically acclaimed and panned movies?"*
- 🎬 *"Do newcomer leads in horror movies produce higher ROI than veterans?"*
- 🥓 *"How many hops connect Kevin Bacon to Meryl Streep?"*
- 📊 *"What genre has the widest gap between critic sentiment and audience popularity?"*
